Aprende a programar desde cero

Un curso completo de lógica de programación con el lenguaje KEM. Cada lección incluye ejemplos en KEM, C++, Python y Java.

Clase 1

¿Qué es programar? Conoce KEM

Programar es dar instrucciones a una computadora para que realice tareas específicas. Piensa en una receta de cocina: son pasos ordenados que, si se siguen, producen un plato. De igual forma, un programa es una lista de pasos que la máquina ejecuta.

Los lenguajes de programación son los idiomas que usamos para escribir esas instrucciones. KEM es un lenguaje creado especialmente para hispanohablantes: sus palabras clave están en español, y puedes cambiarlas a cualquier idioma con un simple archivo JSON.

KEM es un lenguaje compilado JIT (Just-In-Time), lo que significa que tu código se traduce a lenguaje máquina al momento de ejecutarlo, gracias a LLVM. Esto combina la velocidad de lenguajes compilados con la facilidad de los interpretados.

► Para recordar: Un programa es una secuencia de instrucciones que resuelve un problema. KEM te permite escribir esas instrucciones en español.
Ejercicio: Piensa en una tarea cotidiana (por ejemplo, preparar un sándwich) y escribe los pasos en orden. Eso es un algoritmo. Luego, busca en internet qué es un compilador y qué es un intérprete.
Clase 2

Tu primer programa: Hola Mundo

Todo programa en KEM necesita un bloque inicio { }. Dentro de él se escriben las instrucciones que se ejecutarán al correr el programa.

Vamos a escribir el clásico "Hola, mundo!", que simplemente muestra un mensaje en la pantalla.

► Código en KEM

inicio {
    imprimirLinea("¡Hola, mundo!")
}

imprimirLinea es una función integrada que muestra texto y salta a la siguiente línea. También existe imprimir que no salta.

Ahora, veamos el mismo programa en otros lenguajes para que veas las diferencias:

KEM 
inicio {
    imprimirLinea("¡Hola, mundo!")
}
C++ 
#include <iostream>
int main() {
    std::cout << "¡Hola, mundo!" << std::endl;
    return 0;
}
Python 
print("¡Hola, mundo!")
Java 
public class Main {
    public static void main(String[] args) {
        System.out.println("¡Hola, mundo!");
    }
}
► Observa: En KEM no necesitas punto y coma, ni #include, ni una función main separada. El bloque inicio ya es el punto de entrada.
Ejercicio: Modifica el programa para que muestre dos mensajes: "Bienvenido" y "A KEM" en líneas separadas.
Clase 3

Guardando información: Variables

Las variables son como cajas donde guardamos datos. Cada variable tiene un tipo que define qué clase de dato puede almacenar.

En KEM tenemos cuatro tipos básicos:

  • entero: números sin decimal (ej. 5, -3, 0).
  • decimal: números con punto decimal (ej. 3.14, -0.5).
  • texto: cadenas de caracteres, siempre entre comillas dobles (ej. "Hola").
  • booleano: solo dos valores: verdadero o falso.

Para declarar una variable, escribes el tipo y luego el nombre, y opcionalmente la inicializas con =:

entero edad = 25
decimal altura = 1.75
texto nombre = "Ana"
booleano esMayor = verdadero

Puedes cambiar el valor de una variable después con la asignación:

edad = 26
altura = 1.80
KEM 
entero edad = 25
decimal altura = 1.75
texto nombre = "Ana"
booleano esMayor = verdadero
C++ 
int edad = 25;
double altura = 1.75;
std::string nombre = "Ana";
bool esMayor = true;
Python 
edad = 25
altura = 1.75
nombre = "Ana"
esMayor = True
Java 
int edad = 25;
double altura = 1.75;
String nombre = "Ana";
boolean esMayor = true;
► Nota: En Python el tipo es dinámico, no necesitas declararlo explícitamente. En KEM, C++ y Java el tipo es fijo.
Ejercicio: Declara variables para tu nombre, tu edad, tu estatura y si te gusta la pizza. Luego, cambia la edad a un valor mayor.
Clase 4

Interactuando con el usuario

Hasta ahora solo mostramos mensajes. Ahora vamos a leer lo que el usuario escribe para hacer programas más interactivos.

KEM tiene funciones integradas para leer:

  • leerLinea() → devuelve un texto con todo lo que el usuario tecleó hasta presionar Enter.
  • leerEntero() → devuelve un entero.
  • leerDecimal() → devuelve un decimal.

También tenemos funciones para imprimir números:

  • imprimirEntero(entero)
  • imprimirDecimal(decimal)

Ejemplo: preguntar el nombre y la edad, y saludar.

inicio {
    imprimir("¿Cómo te llamas? ")
    texto nombre = leerLinea()
    imprimir("¿Cuántos años tienes? ")
    entero edad = leerEntero()
    imprimir("Hola, ")
    imprimir(nombre)
    imprimir(", el año que viene tendrás ")
    imprimirEntero(edad + 1)
    imprimirLinea(" años.")
}
KEM 
inicio {
    imprimir("¿Cómo te llamas? ")
    texto nombre = leerLinea()
    imprimir("¿Cuántos años tienes? ")
    entero edad = leerEntero()
    imprimir("Hola, ")
    imprimir(nombre)
    imprimir(", el año que viene tendrás ")
    imprimirEntero(edad + 1)
    imprimirLinea(" años.")
}
C++ 
#include <iostream>
#include <string>
using namespace std;
int main() {
    string nombre;
    int edad;
    cout << "¿Cómo te llamas? ";
    getline(cin, nombre);
    cout << "¿Cuántos años tienes? ";
    cin >> edad;
    cout << "Hola, " << nombre << ", el año que viene tendrás " << (edad+1) << " años." << endl;
    return 0;
}
Python 
nombre = input("¿Cómo te llamas? ")
edad = int(input("¿Cuántos años tienes? "))
print("Hola,", nombre, ", el año que viene tendrás", edad+1, "años.")
Java 
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("¿Cómo te llamas? ");
        String nombre = sc.nextLine();
        System.out.print("¿Cuántos años tienes? ");
        int edad = sc.nextInt();
        System.out.println("Hola, " + nombre + ", el año que viene tendrás " + (edad + 1) + " años.");
    }
}

Clase 5

Operaciones con datos

Los operadores nos permiten realizar cálculos y comparaciones.

Operadores aritméticos:

  • + (suma), - (resta), * (multiplicación), / (división), % (módulo o resto).

La división de enteros da un entero (trunca el decimal). Si quieres resultado decimal, al menos uno de los operandos debe ser decimal.

Operadores de comparación (resultan en booleano):

  • == igual, != diferente, <, >, <=, >=

Operadores lógicos (sobre booleanos):

  • y (AND), o (OR), no (NOT)

Ejemplo: calcular el área de un rectángulo.

inicio {
    imprimir("Base: ")
    decimal base = leerDecimal()
    imprimir("Altura: ")
    decimal altura = leerDecimal()
    decimal area = base * altura
    imprimir("El área es: ")
    imprimirDecimal(area)
    imprimirLinea("")
}
KEM 
inicio {
    decimal base = 5.0
    decimal altura = 3.0
    decimal area = base * altura
    imprimirDecimal(area)  // muestra 15.000000
}
C++ 
#include <iostream>
int main() {
    double base = 5.0, altura = 3.0;
    double area = base * altura;
    std::cout << area << std::endl;
    return 0;
}
Python 
base = 5.0
altura = 3.0
area = base * altura
print(area)
Java 
public class Main {
    public static void main(String[] args) {
        double base = 5.0;
        double altura = 3.0;
        double area = base * altura;
        System.out.println(area);
    }
}

Clase 6

Tomando decisiones: si / sino

Los condicionales permiten ejecutar diferentes bloques de código según se cumpla o no una condición.

La sintaxis en KEM:

si condicion {
    // se ejecuta si condicion es verdadera
} sino si otra_condicion {
    // se ejecuta si la primera es falsa y esta es verdadera
} sino {
    // se ejecuta si todas las anteriores son falsas
}

Ejemplo: verificar si un número es positivo, negativo o cero.

inicio {
    imprimir("Ingresa un número: ")
    entero n = leerEntero()
    si n > 0 {
        imprimirLinea("El número es positivo")
    } sino si n < 0 {
        imprimirLinea("El número es negativo")
    } sino {
        imprimirLinea("El número es cero")
    }
}
KEM 
inicio {
    entero n = 5
    si n > 0 {
        imprimirLinea("Positivo")
    } sino si n < 0 {
        imprimirLinea("Negativo")
    } sino {
        imprimirLinea("Cero")
    }
}
C++ 
#include <iostream>
int main() {
    int n = 5;
    if (n > 0) {
        std::cout << "Positivo" << std::endl;
    } else if (n < 0) {
        std::cout << "Negativo" << std::endl;
    } else {
        std::cout << "Cero" << std::endl;
    }
    return 0;
}
Python 
n = 5
if n > 0:
    print("Positivo")
elif n < 0:
    print("Negativo")
else:
    print("Cero")
Java 
public class Main {
    public static void main(String[] args) {
        int n = 5;
        if (n > 0) {
            System.out.println("Positivo");
        } else if (n < 0) {
            System.out.println("Negativo");
        } else {
            System.out.println("Cero");
        }
    }
}

Clase 7

Repitiendo acciones: Bucles

Los bucles repiten un bloque de código varias veces. KEM tiene dos tipos:

  • mientras: repite mientras una condición sea verdadera.
  • hasta: recorre un rango de números enteros (como el for de otros lenguajes).

Ejemplo con mientras: contar del 1 al 5

inicio {
    entero contador = 1
    mientras contador <= 5 {
        imprimirEntero(contador)
        imprimirLinea("")
        contador = contador + 1
    }
}

Ejemplo con hasta: sumar los números del 1 al 10

inicio {
    entero suma = 0
    entero i
    i = 1 hasta 11 {   // i toma valores 1,2,...,10
        suma = suma + i
    }
    imprimir("La suma es: ")
    imprimirEntero(suma)
    imprimirLinea("")
}

El rango de hasta es inicio ≤ i < fin. El valor final no se incluye.

KEM 
entero suma = 0
entero i
i = 1 hasta 11 {
    suma = suma + i
}
C++ 
int suma = 0;
for (int i = 1; i <= 10; i++) {
    suma += i;
}
Python 
suma = 0
for i in range(1, 11):
    suma += i
Java 
int suma = 0;
for (int i = 1; i <= 10; i++) {
    suma += i;
}

Clase 8

Organizando código: Funciones

Las funciones son bloques de código reutilizables. Reciben datos (parámetros) y devuelven un resultado. Los procedimientos son similares pero no devuelven nada (solo ejecutan acciones).

Sintaxis de una función en KEM:

funcion nombre(param1 tipo, param2 tipo) tipo_retorno {
    // cuerpo
    devolver resultado
}

Ejemplo: función que suma dos números.

funcion suma(entero a, entero b) entero {
    devolver a + b
}

inicio {
    entero resultado = suma(5, 3)
    imprimirEntero(resultado)  // 8
}

Los procedimientos no usan devolver (o lo usan sin valor para salir temprano).

KEM 
funcion suma(entero a, entero b) entero {
    devolver a + b
}
C++ 
int suma(int a, int b) {
    return a + b;
}
Python 
def suma(a, b):
    return a + b
Java 
public static int suma(int a, int b) {
    return a + b;
}
Ejercicio: Escribe una función que reciba un número y devuelva verdadero si es par, falso si es impar.
Clase 9

Modificando variables externas

Normalmente, los parámetros se pasan por valor: la función recibe una copia del dato. Si quieres modificar la variable original, usas referencia.

En KEM, antepones referencia al tipo del parámetro.

Ejemplo: un procedimiento que intercambia dos números.

procedimiento intercambiar(referencia entero a, referencia entero b) {
    entero temp = a
    a = b
    b = temp
}

inicio {
    entero x = 5, y = 10
    intercambiar(x, y)
    // ahora x = 10, y = 5
}

Esto no es posible en Python (los tipos simples son inmutables) pero en C++ se usan referencias (&) y en Java se simula con arreglos o envoltorios.

KEM 
procedimiento intercambiar(referencia entero a, referencia entero b) {
    entero temp = a
    a = b
    b = temp
}
C++ 
void intercambiar(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}
Java 
// Java no tiene paso por referencia para tipos primitivos.
// Se simula usando un arreglo de un elemento:
static void intercambiar(int[] a, int[] b) {
    int temp = a[0];
    a[0] = b[0];
    b[0] = temp;
}
// Uso: intercambiar(new int[]{x}, new int[]{y});
Ejercicio: Escribe un procedimiento que reciba un entero por referencia y lo duplique.
Clase 10

Agrupando datos: Arreglos

Un arreglo es una colección de elementos del mismo tipo, almacenados en posiciones consecutivas. Se accede a cada elemento mediante un índice (empezando en 0).

En KEM, declaras un arreglo con tipo nombre[tamaño] y puedes inicializarlo.

entero numeros[5] = [10, 20, 30, 40, 50]
texto nombres[3] = ["Ana", "Luis", "Carlos"]

inicio {
    entero primero = numeros[0]  // 10
    imprimir(nombres[1])         // Luis
    numeros[2] = 99              // modifica el tercer elemento
}

Recorrer un arreglo con un bucle:

inicio {
    entero nums[5] = [2, 4, 6, 8, 10]
    entero i
    i = 0 hasta 5 {
        imprimirEntero(nums[i])
        imprimirLinea("")
    }
}
KEM 
entero nums[5] = [2, 4, 6, 8, 10]
entero i
i = 0 hasta 5 {
    imprimirEntero(nums[i])
}
C++ 
int nums[5] = {2, 4, 6, 8, 10};
for (int i = 0; i < 5; i++) {
    std::cout << nums[i] << std::endl;
}
Python 
nums = [2, 4, 6, 8, 10]
for i in range(len(nums)):
    print(nums[i])
Java 
int[] nums = {2, 4, 6, 8, 10};
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}
► Importante: En KEM, el tamaño del arreglo debe ser una constante conocida en tiempo de compilación. No hay arreglos dinámicos en esta versión.

Clase 11

Datos compuestos: Estructuras

Las estructuras permiten agrupar varios campos de tipos distintos bajo un mismo nombre. Son útiles para representar entidades del mundo real (ej. un punto, un libro, un estudiante).

En KEM, se definen con estructura y se accede a los campos con .

estructura Punto {
    decimal x
    decimal y
}

inicio {
    Punto p
    p.x = 3.5
    p.y = 2.0
    imprimirDecimal(p.x)
}

En esta versión de KEM, las estructuras son parciales (no verifican tipos de campos completamente).

KEM 
estructura Punto {
    decimal x
    decimal y
}
C++ 
struct Punto {
    double x;
    double y;
};
Python 
from dataclasses import dataclass
@dataclass
class Punto:
    x: float
    y: float
Java 
class Punto {
    double x;
    double y;
}
Ejercicio: Define una estructura Libro con título (texto), autor (texto) y páginas (entero). Luego crea una variable de ese tipo y asígnale valores.
Clase 12

Usar funciones de C (enlazar)

KEM puede llamar funciones escritas en C usando la palabra clave enlazar. Esto abre un mundo de posibilidades porque puedes usar cualquier función de la biblioteca estándar de C.

Sintaxis:

enlazar tipo nombre(parametros)

Ejemplo: usar sqrt (raíz cuadrada) de la librería matemática.

enlazar decimal sqrt(decimal)

inicio {
    decimal num = 16.0
    decimal raiz = sqrt(num)
    imprimirDecimal(raiz)  // 4.000000
}

También puedes usar printf aunque con limitaciones (no variádica).

KEM 
enlazar decimal sqrt(decimal)
inicio {
    decimal r = sqrt(25.0)
    imprimirDecimal(r)
}
C++ 
#include <cmath>
#include <iostream>
int main() {
    double r = sqrt(25.0);
    std::cout << r << std::endl;
}
Python 
import math
r = math.sqrt(25.0)
print(r)
Java 
public class Main {
    public static void main(String[] args) {
        double r = Math.sqrt(25.0);
        System.out.println(r);
    }
}
