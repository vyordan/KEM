Comunidad

KEM es un proyecto de código abierto. Tu contribución es bienvenida.

GitHub

El repositorio principal de KEM está en GitHub. Aquí puedes:

  • Reportar bugs o sugerir mejoras abriendo un issue.
  • Desarrollar nuevas funcionalidades para el compilador: haz un fork del proyecto, trabaja en tu rama y luego envía un pull request hacia la rama main para que tus cambios sean revisados e incorporados.
